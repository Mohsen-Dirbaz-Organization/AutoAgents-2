# AgentEvent

## Overview
Represents events generated by agents during their lifecycle and operations.

## Purpose
The `AgentEvent` class encapsulates event information specific to agent activities, enabling event-driven communication and system monitoring.

## Key Components

### Event Properties
- Event type and category
- Source agent identifier
- Timestamp
- Event payload
- Priority level
- Correlation ID

### Event Types
- Lifecycle events (start, stop, pause, resume)
- State change events
- Task-related events
- Communication events
- Error and warning events

### Methods
- Event creation and validation
- Payload serialization
- Event routing information
- Event filtering criteria

## Usage
Generated by agents and consumed by event handlers, monitors, and other agents.

## Integration Points
- `EventBus`: Distributes agent events
- `Agent`: Generates events
- `ObserverAgent`: Monitors agent events
- `HistoryManager`: Records event history

## Related Classes
- `AgentState`: State changes trigger events
- `EventBus`: Event distribution mechanism
- `MessageType`: Event categorization
